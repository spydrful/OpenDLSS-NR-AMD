AMD RGP container schema attribution

tools/validate_rgp_container.py is an independently written metadata reader.
It follows publicly documented AMD RDF and PAL field layouts; no AMD library,
driver implementation or profiler analysis backend is included.

AMD libamdrdf schema/documentation:
https://github.com/GPUOpen-Drivers/libamdrdf/tree/1f13ba88fa0753d908d5fba82fe4483406267b80
