# OpenNR AMD Alpha 6

An **experimental Windows build for Radeon RX 9070 XT and Cyberpunk 2077**. This release is for trying and validating neural rendering (NR); performance and broad game-quality targets remain unmet. **NR starts disabled.**

## What changed

- Adds an optional faster step in the neural network, called **C32 QKV projection/normalization**. It reduced network-only median GPU time by **5.28923%** in the same-build comparison at 1707 × 960 input.
- Makes Vulkan buffer dependencies explicit for uploads, fills and diagnostic readback.
- Keeps NR and the new C32 path off by default. Installing this build does not automatically select Pair/Arena or C32.

## Get started

The tested setup is **Windows 11, RX 9070 XT, Adrenalin 26.9.1 and Cyberpunk 2077 2.31**, plus **PowerShell 7**, the **Microsoft Visual C++ v14 x64 runtime**, and your own supported local model DLL (pinned DLSS-NR 310.8.0 or 310.8.SF.0).

1. Download the ZIP and checksum, verify the hash, and extract the package. Keep it for removal.
2. Close the game. Follow the [installation guide](../INSTALL.md) to install into the folder containing `Cyberpunk2077.exe` (normally `bin\x64`). Preview the install with `-WhatIf` first.
3. Import your supported model locally using the guide. The importer reads the DLL without executing it; reuse an existing verified model rather than overwriting it.
4. Start with **2560 × 1440 output, FSR Quality, ray tracing off, frame generation off and driver AFMF off**. Launch the game, then press **Insert → Neural → Enable NR** when ready to test.

Use **Enable NR** to turn inference off again. Setting effect strengths to zero still runs the network.

The linked online guide has been simplified after publication. The package still includes its frozen INSTALL.md; [that original guide](https://github.com/spydrful/OpenDLSS-NR-AMD/blob/v0.1.0-alpha.6/docs/INSTALL.md) retains the exact release instructions. Optional Pair/Arena+C32 selections and diagnostic recipes are explained in the [advanced guide](../ADVANCED.md). These selections require a game restart and do not enable NR by themselves.

## Upgrade or go back

Close the game and remove the current OpenNR installation using its own retained package before installing another version. Keep the extracted packages, the game's `.open-nr-install.json` ledger and `.open-nr-backup-*` folder. The scripts verify managed files and restore backed-up originals.

If you edited a managed INI or another installed file, preserve it and follow the guide before uninstalling; changed managed files can block removal. Imported models remain after uninstall. To return to an earlier release, uninstall this one, install that release using its own package and guide, and keep its packaged defaults.

## Known limits

The 5.28923% improvement measures the neural network alone, excluding the bridge, FSR and gameplay. Alpha 6 game FPS, bridge time and VRAM have not been measured. The 8 ms NR-plus-bridge and 60 real FPS targets remain unmet.

Broad motion, faces, disocclusion, exposure, ghosting and highlight acceptance remain incomplete. Some HDR/highlight reference-quality checks still fail. Original NVIDIA-runtime parity, RX 7000 acceleration, other games/platforms, ray tracing and HDR display validation are unclaimed. The full validation scope and measurements remain below.

[Report an issue](https://github.com/spydrful/OpenDLSS-NR-AMD/issues/new) with the release version, GPU/driver, game settings, selected NR options and exact error text. Keep proprietary DLLs, model files and game captures out of attachments.

## Measured network improvement

The final production build compares QKV normalization **off versus c32** with
explicit Pair/Arena, K16/N16/stage16/Q32 and every other fusion/packed-publication
override off. At valid **1707×960**, padded to **1728×960**:

| Ordinary network GPU time | QKV normalization off | C32 route on |
| --- | ---: | ---: |
| Median | 50.41260 ms | **47.74616 ms** |
| P95 | 50.63238 ms | **48.02880 ms** |
| P99 | 50.78920 ms | **48.68730 ms** |

Median improvement is **5.28923%**. Five warmups and three interleaved pairs of
30 measured frames retain 90 samples per condition, without image readback or
dispatch instrumentation. Windows 11, RX 9070 XT and Adrenalin 26.9.1 (LLPC) are
the tested environment. This is a **same-build network-only comparison**,
excluding D3D12/Vulkan bridge time, FSR, gameplay and presentation. It does not
reuse historical alpha 5 timing as its baseline.

A separate 1920×1080 comparison, padded to 1920×1152, measures **67.998940 →
64.429200 ms median**, **68.305334 → 64.769944 ms P95** and **68.329182 →
64.847955 ms P99**: **5.249699% median improvement** with the same ordinary
protocol. This establishes no additional 1080p image-quality or game claim.

The **8 ms NR-plus-bridge** and **16.67 ms / 60 real FPS** targets remain unmet.
Alpha 6 Cyberpunk FPS, game bridge time and VRAM have not been measured. Historical
alpha 3's 97.12 FPS NR off / 10.69 FPS NR on describe its original runtime only.
See the [delivery record](../amd-qkv-normalize-delivery.md) and
[scalar evidence](../performance/qkv-normalize-rx9070xt-20261003.json).

## Included changes and validation

- `--amd-qkv-normalize off|c32` and `DLSS5VK_AMD_QKV_NORMALIZE` expose an
  independent route, read once when creating a runtime session. The `c32` choice
  requires optimized Pair/Arena, K16/N16/stage16/Q32, every other fusion and
  hardware-publication override off, and an empty tuning path.
- Exactly blocks 0–4/66–70 use the K32/N96/head1 fused projection/normalization
  with raw model weights, ordered K16 publication, the original scalar half
  reduction tree and a shared bridge. Installed-driver resources are 9,216 bytes
  LDS, 32 VGPRs, 22 SGPRs and 0 scratch bytes. Model/module identities, supported
  matrix and float controls, memory bounds and output aliasing are checked.
- Uploads, fills and diagnostic readback have explicit Vulkan dependencies.
  Timed runs exclude image readback; native bridge synchronization remains intact.
- A source-only [C32 diagnostic script](../../scripts/probe_amd_c32_qkv_normalize.ps1)
  builds isolated operator/capture/timing tools. Build is CPU-only; GPU execution
  is explicit, and timing requires the matching strict proof. Diagnostic
  executables, capture shaders and generated tensors are excluded from payloads.
- The final build passes all 75 decomposed 320×320 boundaries plus the F32 head,
  separate fused production-head reproduction and target-head reproduction.
  Intermediate capture decomposes the same selected Pair K16 arithmetic and
  original normalization.
- Eighteen synthetic SDR/HDR buffers preserve previous AMD bytes. Eight existing
  genuine SDR frames in identical and independently evolved histories pass
  **80 raw checks / 2,107,883,520 bytes**, comprising 48 fresh candidate outputs
  and 32 copied original runtime anchors. Sixteen freshly computed composed RGB
  comparisons match the Pair/Arena AMD baseline exactly. Evolved history uses
  each variant's own reset and does not claim original captured ancestry.
  These are preservation checks; existing
  absolute-reference highlight failures remain.
- Native DLL lifecycle tests pass eight sequential frames and separate eight-live
  slot pool checks at 320×320 and full target geometry, including ordered frames,
  cancellation, gaps and resets. This is no claim of concurrent inference or game
  performance. Dedicated diagnostic and package/source-rebuild proofs are bound
  separately at delivery.

No new game scenes or visual review are added. Broad motion/face/disocclusion/
exposure/flicker/ghosting review, highlight quality acceptance, three warmed
complete Cyberpunk benchmarks and ten minutes of active gameplay remain pending.
Original NVIDIA parity, RX 7000, other games/platforms, ray tracing and HDR display
validation are unclaimed.

## Install and opt in

Download the ZIP and sidecar; GitHub's automatic source
archives contain no built DLLs. Follow the [installation guide](../INSTALL.md),
including its process-only Pair/Arena+C32 selection. Remove an earlier OpenNR
installation with its retained package before installing another version.

Use Windows 11, RX 9070 XT, PowerShell 7, the Microsoft Visual C++ v14 x64 runtime
and the tested AMD Vulkan driver. The initial game target is Cyberpunk 2077 2.31
at 1440p output, FSR Quality, ray tracing, frame generation and AFMF off. Kernel
selection does not enable NR; use Insert → Neural → Enable NR deliberately.
Zero effect strength still runs inference. Restart the game after changing
process selections; closing that PowerShell window restores the ordinary launch
environment. Install/remove scripts retain backups and verify managed hashes.

NVIDIA DLLs, extracted weights and game captures are excluded. Supply a supported
model DLL locally; the importer reads it without executing it. The package
retains MIT core/importer attribution, GPL host corresponding source and all
dependency notices. No generated weights enter source or release packages.
