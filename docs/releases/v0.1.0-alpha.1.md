# RX 9070 XT native Windows alpha 1

This alpha packages the native AMD Vulkan neural runtime and patched D3D12
OptiScaler integration for **Cyberpunk 2077 on RX 9070 XT**. It is for development
testing: **performance and game-quality release gates are still unmet**.

**NR is disabled by default.** Enabled NR measured **4.56 / 4.56 / 4.57 FPS** in
three warmed built-in benchmark runs at 2560 x 1440 output, High graphics fields
(the edited preset reads Custom), FSR Quality, ray tracing and in-game frame
generation off. NR plus its bridge took about **213 ms**, far above the 8 ms
initial budget and 16.67 ms total frame budget for 60 FPS. Driver AFMF could not
be verified; these results do not assert real-rendered FPS.

## Download and install

Download **OpenNR-AMD-v0.1.0-alpha.1-rx9070xt.zip** and **.zip.sha256** from the
assets below. The ZIP includes prebuilt binaries, importer and diagnostic tools,
install/remove scripts, license notices and corresponding source. GitHub's
automatic **Source code** archives do not include the built DLLs.

Follow the [installation guide](https://github.com/spydrful/OpenDLSS-NR-AMD/blob/v0.1.0-alpha.1/docs/INSTALL.md)
or the included `INSTALL.md`. Requirements are Windows 11, RX 9070 XT, a driver
with the required RDNA4 FP8/wave32 capabilities, PowerShell 7, Microsoft Visual
C++ v14 Redistributable x64, an installed game and your own supported local
model DLL. Adrenalin 26.9.1 and Cyberpunk 2077 2.31 are the tested versions.

Install into the game's **bin/x64** directory while the game is closed. Import
your own supported DLSS-NR 310.8.0 or pinned 310.8.SF.0 container locally; the
importer parses it without loading or executing the DLL. The guide lists the
exact accepted hashes. **No NVIDIA DLL, model weights or game assets are
distributed.**

After import, press **Insert → Neural → Enable NR** to opt in. Use that checkbox
to disable inference; setting effect strength to zero still runs the network.
Keep the extracted package and install backups for reversible removal. If
saving settings changes a managed INI, follow the guide to preserve it before
removing or upgrading.

## Included work

- RDNA4 FP8 matrix kernels, AMD capability checks, weight layouts and scratch
  reuse, with explicit Vulkan barriers.
- A separate exact diagnostic implementation and backend-selectable CLI.
- Native D3D12/Vulkan adapter matching, shared GPU buffers and fences, GPU
  exposure and scene-linear output before FSR, motion and temporal history.
- Versioned frame lifecycle API, cancellation/reset/drain handling and
  command-list/resource-state preservation.
- Strict local model importer and hash-checked install/remove scripts.
- Core MIT and GPL adapter notices, pinned host source, static dependency source
  archives and Windows build scripts under `source/`.

## Validation and limits

The direct WGSL and portable Vulkan diagnostics match 76 model checkpoints at
320 x 320. Importer tests pass 213 checks. The controlled D3D12 harness covers
shared-buffer/fence round trips, eight queued frames, cancellation/recovery,
resize/reset/drain and continuation state. Delivered source rebuilt the core,
shaders, runtime, importer and patched host in a fresh directory during prior
validation.

Synthetic SDR comparisons meet PSNR ≥40 dB and SSIM ≥0.99. Synthetic HDR
scene-linear cases fail one or both thresholds. Corrected genuine game captures
and broad motion, faces, ghosting, camera cuts and disocclusion review are still
pending. No original NVIDIA runtime parity is claimed. A preserved one-frame
comparison has an incorrect provenance flag and is not accepted as genuine
game-quality evidence.

The packaged runtime includes the executable-name capture classification fix;
the performance record identifies the earlier measured runtime separately.
This packaging release does not claim a new game benchmark of that metadata
fix. The [validation record](https://github.com/spydrful/OpenDLSS-NR-AMD/blob/v0.1.0-alpha.1/docs/rx9070xt-validation.md)
contains exact binary/model/driver identities, frame-time percentiles and scope.

RX 9070 XT is the sole validated GPU. RX 7000 acceleration, Linux, other games,
ray tracing and HDR display validation remain later work. Report reproducible
issues with versions, settings, status, timings and error text; exclude
proprietary DLLs, model files and captures from attachments.
